Архитектурный фокус
Мультиагентные и линейные воркфлоу: прагматичный выбор между детерминированными пайплайнами и графами агентов (Orchestrator-Workers, Router, Evaluator).
Контроль контекста и памяти: атомарная версионная документация (INDEX.md + STATE.json), гибридный RAG с фильтрацией устаревших ревизий.
Безопасность по умолчанию: изоляция секретов на бэкенде, ролевой доступ к БД (RLS / JWT), белые списки инструментов для агентов и защита от Prompt Injection.
